# Papan tugas kelompok — usulan awal

Pembagian berikut adalah usulan untuk memulai. Kelompok boleh mengubahnya sesuai kemampuan, tetapi pastikan setiap anggota memiliki commit dan kontribusi yang dapat dibuktikan.

## Urutan kerja tim

1. Semua anggota menyelesaikan setup Docker dan berhasil membuka aplikasi lokal.
2. Buat repository GitHub bersama dan `develop` branch.
3. Kerjakan fitur pada branch masing-masing, bukan langsung di `main`.
4. Setiap Pull Request harus memiliki deskripsi, screenshot atau langkah uji, dan minimal satu reviewer.
5. Setiap milestone diuji bersama sebelum merge ke `main`.
6. Catat ulang pembagian jika beban kerja tidak seimbang.
